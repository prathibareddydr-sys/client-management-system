# Client Lead Management System (Mini CRM)

A simple web-based Client Lead Management System built as part of the Future Interns Full Stack Web Development Internship – Task 2.

## Features

- Add new leads
- Edit and update lead details
- Delete leads
- Search leads
- Update lead status
- Lead statuses: New, Contacted, Converted
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Project Structure

- `index.html` – Main webpage
- `style.css` – Styling
- `script.js` – Lead management functionality

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. You can also use Live Server in VS Code.
